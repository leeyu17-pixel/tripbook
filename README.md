# 移动端自适应旅行手册 (Travel Manual Template)

一款专为手机移动端量身打造的高质感、纯离线、零外部依赖的旅行手册模板。设计灵感汲取自小红书爆款旅行攻略，兼具实体拟物车票感与便捷的高德地图交互。

## 🌟 特性
- 📱 **原生 App 级手感**：柔和米色纸质调配色（`#f7f6f1`），拟物车票/登机牌卡片排版。
- 🧭 **高德地图深度整合**：点击景点名直接呼起高德 App 并精确定位至对应坐标，支持路线规划。
- 📖 **优雅就地展开**：点击景点旁 `ⓘ` 图标原地展开一段式精辟总结（避坑、看点、背景）。
- ⏱️ **绝对时间感知展开**：根据上海时间（北京时间）自动展开当前天数的行程手风琴，其余日期自动折叠。
- 🗂️ **本地持久化记忆**：待办清单勾选进度自动存入浏览器 LocalStorage，刷新不丢失。
- 📦 **零构建环境**：无需 Node.js、无需编译，双击即可在任何浏览器打开，或通过 GitHub Pages 秒级发布。

## 🚀 下次如何生成新行程？

下次去任何城市（例如：**西双版纳 4 天 3 晚**），直接把你的航班/酒店截图或粗略行程发给 AI，并附上以下提示词：

> **“请严格按照我现有 `trip-data.js` 的 JSON 数据格式，为我整理生成一份【西双版纳 4 天 3 晚】的 `const TRIP_DATA = { ... };` 数据代码。要求包含倒计时节点、拟物化航班与住宿信息、高德地图经纬度坐标、景点一段式总结与注意事项。”**

获取新的 `TRIP_DATA` 后，**仅需替换 `trip-data.js` 中的内容并提交到 GitHub**，网页就会自动换上全新的行程。
